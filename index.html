Gemini API 키 설정

AI 초안 작성 기능을 사용하려면 본인의 무료 Google Gemini API 키가 필요합니다. (템플릿 기능은 키 없이도 상시 무료 이용 가능합니다.)

🔑 API 키 무료 발급 받는 방법:

  1. Google AI Studio에 접속하여 로그인합니다.
  2. 상단 또는 좌측의 'Get API key' 버튼을 클릭합니다.
  3. 'Create API key'를 눌러 키를 생성한 뒤 복사합니다.
