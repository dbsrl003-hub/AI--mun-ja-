Gemini API 키 등록

AI 자동 문자 작성 기능을 이용하기 위해 Google Gemini API 키가 필요합니다.
입력하신 API 키는 서버에 저장되지 않고 사용자의 브라우저에만 안전하게 보관됩니다.

API 키 무료 발급받는 방법

  1. 구글 계정에 로그인한 상태에서 Google AI Studio 접속
  2. [Create API key] 또는 [Get API key] 버튼 클릭
  3. 생성된 팝업 창에서 생성 버튼을 누르고 API 키 복사
  4. 위 입력 칸에 붙여넣기 후 [저장 및 시작하기] 버튼 클릭
